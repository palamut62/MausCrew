# Python dependencies for server/bridges/deepseek/bridge.py.
#
# Pinned exactly, not floated. The bridge protocol version this build speaks
# is validated against one SDK release; a newer SDK can change the runtime's
# notification shapes, which is precisely what the handshake exists to catch.
# Bump this together with PROTOCOL_VERSION only after re-running the driver's
# live-SDK tests.
#
# Install for the interpreter configured in Settings → Engines → DeepSeek
# Harness (on Windows, inside the WSL distribution):
#
#     python3 -m pip install --pre -r requirements-deepseek.txt
#
# The SDK is still pre-release, so --pre is required. This file verifies the
# two entries it hashes; it is NOT a `--require-hashes`-clean file by itself
# (pip's hash-checking mode demands a hash for every package it installs,
# including pydantic and its transitive dependencies, which are intentionally
# left unpinned here — see below). Plain `pip install -r` still checks each
# hashed entry's digest against what it downloads and refuses a mismatch.
#
# Hash pinning (spec §66): the two hashed entries below are the direct
# dependency and its platform-specific runtime binary, fetched from PyPI's
# JSON API for the exact pinned version — not computed locally, so a
# corrupted or substituted download fails closed instead of installing
# silently. Full `--require-hashes` mode needs the whole transitive tree
# hashed, so pydantic and its own dependencies are intentionally NOT pinned
# here: doing that by hand invites a stale hash blocking a legitimate patch
# release. Generate a full transitive lock instead when a hash-checked
# install is required end to end:
#
#     pip install pip-tools
#     pip-compile --generate-hashes --allow-unsafe --pre \
#         --output-file requirements-deepseek.lock.txt requirements-deepseek.in
#
# (where requirements-deepseek.in contains just `deepseek-harness-sdk==0.1.0rc6`).
# That command must run on each target platform, since pydantic-core and
# deepseek-harness-runtime-bin ship separate wheels per platform.
deepseek-harness-sdk==0.1.0rc6 \
    --hash=sha256:8a05421be4298196cf94383e0a3164b020f5f5977a8d30019cc5add64cb208eb

# payload (the packaged dsh-jsonrpc-agent runtime executable) and its

# One hash per platform pip may resolve to; pip picks the matching wheel and
# ignores the others, so listing all three is correct on every OS, not just
